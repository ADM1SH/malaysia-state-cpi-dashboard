# Malaysia State CPI Dashboard & Retail Pressure Index

Cost of living analysis across all 16 Malaysian states and Federal Territories using official data from **Economic Outlook 2027 (Table 3.16)**. Features a composite **Retail Pressure Index (RPI)** mapped directly onto HYGR's primary operating regions (Klang Valley, Penang, Sabah, and Sarawak).

## Installation & Running

```bash
pip install -r requirements.txt
pytest -v
streamlit run app.py
```
